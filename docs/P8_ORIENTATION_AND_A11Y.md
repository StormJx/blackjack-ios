## 第一切片（优先，未实现）

目标：竖屏下「可玩级」无障碍与大字体，**不含横屏**。

### 布局

1. `SessionBetPanel` / `SessionRoundEndPanel`（及外层 overlay）改为可滚动；大字体 / 小屏下「确认并发牌」「继续 / 返回主页」仍可达。
2. 娱乐道具两行网格在动态字体放大时不严重挤压要牌 / 停牌。
3. 抽查欢迎页标题：避免仅用固定 `size: 44` 导致大字号截断（可改 `Font.largeTitle` + 缩放上限）。

### VoiceOver

1. 下注面板：余额、当前注、档位选中态、全下锁定原因、确认按钮。
2. 牌桌：玩家/庄家点数、明牌点数、筹码行（你 / 庄家 / 注）。
3. 主操作：要牌 / 停牌补充 hint；道具禁用时读**具体原因**（本局已用 / 需先要牌 / 窥视中等），勿仅「当前不可用」。
4. 局末：盈亏、赔率、双方余额、会话结束原因、成就提示。
5. 洗牌页：保留「洗牌中」，可补充切牌模式简述。

### 动态效果与对比

1. `ShuffleScreenOverlay` 尊重 `accessibilityReduceMotion`（减弱或静止）。
2. 禁用态不单靠透明度：保留文案或图标语义（下注档不足、全下锁定原因已有 caption 可复用）。
3. 深色模式下结果色 / 禁用态对比度抽查。

### 文案 polish（可同切片）

- 设置页反馈区去掉面向开发者的 `Sounds/`、wav/mp3 技术说明，改为用户向短句。

### 验收

- iPhone SE / 标准机 + 最大动态字体：下注与局末主按钮可见可点。
- VoiceOver 走完：欢迎 → 娱乐开局 → 下注 → 要牌/停牌 → 局末 → 返回。
- 开启「减弱动态效果」时洗牌页无无限脉冲动画。

## 横竖屏（后置）

现状：工程仅支持竖屏（`UISupportedInterfaceOrientations = Portrait`）；`TARGETED_DEVICE_FAMILY = 1`（iPhone）。

建议后续：

1. 评估是否允许横屏；若允许，牌桌操作区与手牌区需重排（横屏高度紧）。
2. iPad / 分屏尺寸变化时避免裁切主按钮（若日后支持 iPad）。
3. 默认仍可保持竖屏优先；横屏为增强项。
4. **先完成第一切片再做横屏**，避免两套布局同时改。
