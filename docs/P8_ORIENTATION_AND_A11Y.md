## 第一切片（已完成 · 2026-07-28）

目标：竖屏下「可玩级」无障碍与大字体，**不含横屏**。

### 布局

1. [x] `SessionBetPanel` / `SessionRoundEndPanel`：内容可滚动；「确认并发牌」「继续 / 返回主页」粘性底部，大字体下仍可达。
2. [x] 娱乐道具网格：`ViewThatFits` + 可滚动控件区，动态字体放大时不严重挤压要牌 / 停牌。
3. [x] 欢迎页标题：`Font.largeTitle` + `minimumScaleFactor`，避免固定 `size: 44` 截断。

### VoiceOver

1. [x] 下注面板：余额、当前注、档位选中态、全下锁定原因、确认按钮。
2. [x] 牌桌：玩家/庄家点数、筹码行（你 / 庄家 / 注）。
3. [x] 主操作：要牌 / 停牌 hint；道具禁用读**具体原因**（本局已用 / 需先要牌 / 窥视中等）。
4. [x] 局末：盈亏、双方余额、会话结束、成就提示。
5. [x] 洗牌页：保留「洗牌中」+ 切牌模式简述。

### 动态效果与对比

1. [x] `ShuffleScreenOverlay` 尊重 `accessibilityReduceMotion`（静止扇形，无脉冲循环）。
2. [x] 禁用态保留文案 / accessibilityHint（不单靠透明度）。
3. [ ] 深色模式下结果色 / 禁用态对比度抽查（实机抽查，未单测）。

## 横竖屏（后置）

现状：工程仅支持竖屏（`UISupportedInterfaceOrientations = Portrait`）；`TARGETED_DEVICE_FAMILY = 1`（iPhone）。

建议后续：

1. 评估是否允许横屏；若允许，牌桌操作区与手牌区需重排（横屏高度紧）。
2. iPad / 分屏尺寸变化时避免裁切主按钮（若日后支持 iPad）。
3. 默认仍可保持竖屏优先；横屏为增强项。
4. **第一切片已完成；横屏仍后置。**
